# JiboTube Pro

Browse YouTube and YouTube Music, search by touch keyboard or voice, and watch videos on Jibo's face. Includes related videos, local history and likes, resume, autoplay, looping, captions, volume controls, and SponsorBlock support. Swipe down to exit.

Version 1.1.1 brings the Phoenix screen redesign to Pro: larger controls and text, a single player control row, consistent Back navigation, clear paused state, bounded loading, automatic playback recovery, and plain-language errors with one recovery action. Pro retains its native BE player, 480p/30fps defaults, and existing saved library.
